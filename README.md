MiniReel 是一款支持 Android 和 Windows 的短剧播放器。找一部感兴趣的短剧，用顺手的操作观看；喜欢就收藏，下次打开接着看。

## 能做什么

- **发现短剧**：浏览真人剧、漫剧、AI 剧和动漫，按题材、状态与集数筛选。
- **沉浸观看**：竖屏、横屏随时切换，支持选集、倍速和自动播放下一集。
- **顺手控制**：滑动调节亮度、音量与进度，长按临时加速，锁定屏幕减少误触。
- **桌面观看**：Windows 使用窄图标侧栏，支持键盘控制、全屏、适应视频的窗口和迷你置顶。
- **继续追剧**：收藏喜欢的故事，记住看到了哪一集、哪个时间点。
- **按习惯调整**：浅色、深色、跟随系统和大字模式，控制栏位置与手势灵敏度也能调整。

无需注册账号，收藏、观看记录和设置保存在设备本地。目前以在线播放为主，暂不提供离线下载和多设备同步。

## 获取应用

从 [Releases](https://github.com/WEP-56/minireel/releases) 获取安装包：Windows 下载 `windows-x64-setup.exe` 安装程序，Android 按设备架构下载 APK（多数近年手机使用 `arm64-v8a`）。带 beta、rc 的版本属于预发布版。想自行构建可查看[构建说明](docs/BUILDING.md)。

| 平台 | 支持情况 |
| --- | --- |
| Android 7.0 及以上 | 当前支持 |
| Windows 10 / 11 x64 | 当前支持 |

暂无 macOS 和 iOS 版本计划。

## 开始观看

1. 在「短剧库」浏览、筛选或搜索短剧，点击封面开始播放；长按封面可查看简介和分集。
2. 在播放菜单中选集、收藏或调整倍速。点击屏幕边缘的小胶囊，还能打开播放控制栏。
3. 在「我的」查看收藏和观看历史，接着上次的位置继续看。

## Windows 怎么操作

左侧三枚图标分别进入「短剧库」「我的」和「设置」，鼠标悬停可查看名称。点击封面播放，右键封面查看详情。播放时隐藏导航，控制栏和光标会在闲置后自动收起，移动鼠标即可唤出。

| 操作 | 效果 |
| --- | --- |
| 单击画面 / 空格 | 播放 / 暂停 |
| 双击画面 / F / Enter | 进入 / 退出全屏 |
| ← / → | 后退 / 前进 5 秒 |
| Shift + ← / → | 后退 / 前进 15 秒 |
| ↑ / ↓ | 调整应用音量，每次 5% |
| M | 静音 / 恢复音量 |
| PageUp / PageDown | 上一集 / 下一集 |
| E | 打开选集 |
| 右键画面 | 打开播放菜单 |
| Esc | 依次关闭面板、退出全屏或小窗、返回剧库 |

播放菜单提供「适应视频窗口」「迷你置顶」和「窗口置顶」。切换窗口模式会保留当前播放；全屏时视频保持原比例，选集面板也不会挤动画面。拖动播放器顶部的剧名区域可以移动窗口。

切换到其他应用时继续播放；默认最小化会暂停，可在设置中关闭。锁屏和系统休眠会暂停，恢复时保留原来的暂停意图。窗口位置、尺寸、音量和观看记录会保存在本机。

## Android 竖屏怎么操作

| 操作 | 效果 |
| --- | --- |
| 单击视频 | 播放 / 暂停 |
| 上半区长按 | 打开播放菜单 |
| 下半区长按 | 临时 2 倍速，松手恢复原倍速 |
| 下半区长按后左右滑动 | 预览进度，松手跳转 |
| 左侧上下滑动 | 调节亮度 |
| 右侧上下滑动 | 调节音量 |
| 中部上滑 / 下滑 | 下一集 / 上一集 |
| 点击侧边胶囊 | 展开控制栏，查看时间、拖动进度、切换横屏或锁定屏幕 |

侧栏的进度条**从上向下前进**，上方显示当前时间，下方显示总时长。控制栏可以在设置中改到左侧。

## Android 横屏怎么操作

通过竖屏控制栏中的横屏按钮进入。横屏下使用底部控制栏，时间、进度、选集和倍速放在一起。

| 操作 | 效果 |
| --- | --- |
| 单击视频 | 显示 / 隐藏控制栏 |
| 左右滑动 | 调整进度，松手跳转 |
| 长按视频 | 临时 2 倍速 |
| 左半屏 / 右半屏上下滑动 | 调节亮度 / 音量 |
| 点击控制栏播放按钮 | 播放 / 暂停 |
| 点击竖屏按钮或按返回键 | 回到竖屏，继续当前视频 |

锁定后只保留一个小锁图标，触摸视频不会弹出提示或改变播放。点击小锁即可解锁。

## 常见问题

**有些短剧为什么看不了？**

片源服务可能暂时没有提供有效视频，或某一集的地址已经失效。MiniReel 会尝试可用的备用片源；仍不可用时，可以稍后重试或先看其他短剧。反馈时请附上剧名、集数和错误提示。

**为什么搜索不到某部剧？**

搜索范围是当前已加载的剧库。可以继续加载更多短剧、刷新列表，或换一个更短的关键词。

**播放手势不太顺手？**

在「设置」中调整手势灵敏度和控制栏位置，也可以重新查看手势说明。容易误触时，可降低灵敏度或锁定屏幕。

**清理缓存会丢失观看记录吗？**

应用内的「清理剧库缓存」会保留收藏、观看记录和设置，之后重新刷新即可加载剧库。
