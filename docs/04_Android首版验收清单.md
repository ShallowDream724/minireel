# MiniReel Android 首版验收清单

范围：Android 首版；Windows 留待后续，不验收 macOS / iOS。以下项目留给人工逐项勾选。建议先完成 P0，再检查 P1。

使用普通应用入口运行：在项目根目录执行 `flutter run -d <设备ID>`。自行生成安装包使用 `flutter build apk --release`；目前 release 构建沿用开发签名，适合本地验收。

## P0 · 竖屏播放器手势

| 完成 | 操作 | 预期结果 |
| --- | --- | --- |
| ☐ | 首次打开短剧，关闭手势说明，再退出重进 | 首次说明可关闭，之后不重复遮挡播放；设置中仍可查看说明 |
| ☐ | 单击视频区域两次 | 暂停 → 恢复；单击同时短暂显示顶部信息，没有重复触发 |
| ☐ | 上半区长按约 0.4 秒 | 打开播放菜单并暂停；松手不会额外触发单击 |
| ☐ | 播放中、暂停中分别打开再关闭菜单 | 关闭后恢复打开菜单前的播放/暂停状态 |
| ☐ | 下半区长按，随后松开 | 按住时临时 2 倍速并显示提示，松手恢复原倍速 |
| ☐ | 先设为 1.5 倍速，再下半区长按并松开 | 1.5x → 临时 2x → 1.5x |
| ☐ | 下半区长按后左右滑动，再松手 | 显示目标时间与变化秒数；松手跳到预览位置，不切集、不调整亮度/音量 |
| ☐ | 进度预览拖到视频起点和终点之外 | 时间限制在有效范围内，不出现负数或超出时长 |
| ☐ | 长按/拖动过程中加入第二根手指，或下拉通知栏中断触摸 | 取消临时倍速和进度预览，不误提交进度、不额外暂停/播放 |
| ☐ | 左侧上下滑动 | 调节实际屏幕亮度并显示反馈，不调整音量或切集 |
| ☐ | 右侧上下滑动；再按手机实体音量键后继续滑动 | 调节实际播放音量；新的滑动以当前系统音量为起点 |
| ☐ | 未长按时做普通横向滑动 | 不误触亮度、音量、选集或倍速 |
| ☐ | 中部上滑、下滑，各做一次较长滑动 | 分别下一集、上一集；每次手势最多切换一集 |
| ☐ | 第一集下滑、最后一集上滑 | 提示已经到边界，保持当前集，不越界或循环到其他集 |
| ☐ | 从屏幕最左/最右边缘做系统返回手势 | 系统返回正常；边缘不误触亮度、音量或长按倍速 |

## P0 · 真实播放与生命周期

| 完成 | 操作 | 预期结果 |
| --- | --- | --- |
| ☐ | 从剧库点开短剧并选第 2 集、中间集、末集 | 剧名、集数、实际视频内容对应；不会把试看第一集当成其他集 |
| ☐ | 快速连续切换多集，尤其在加载过程中继续切集 | 最终只播放最后选择的一集，旧请求不会把画面或音频切回去 |
| ☐ | 播放普通直链、HLS、备用接口提供的加密视频 | 有正常画面和声音，音画同步，可暂停、恢复、跳转进度 |
| ☐ | 连续播放两集加密视频，再切回普通视频 | 更换每集密钥后正常播放，上一集密钥不影响下一集 |
| ☐ | 播放中切换实际可用画质 | 画面成功切换，保留当前进度；只有一种画质时如实显示一种 |
| ☐ | 开启/关闭自动下一集，分别播放到结尾 | 开启时自动下一集，关闭时停在当前集；最后一集正常停止 |
| ☐ | 播放中退到后台、锁屏、再回到前台 | 后台/锁屏暂停，无后台残留声音；返回后恢复原状态 |
| ☐ | 先手动暂停，再切后台和回前台 | 不擅自恢复播放 |
| ☐ | 加载分集时退出播放器；播放时直接返回剧库 | 页面退出后不继续取流开播，不残留音频；再次打开仍可播放 |
| ☐ | 调整亮度后退出播放器 | 恢复进入播放器前的应用/系统亮度状态 |
| ☐ | 持续播放数分钟，再暂停或退出 | 播放时保持屏幕常亮；暂停/退出后不持续阻止系统休眠 |
| ☐ | 断网、弱网、网络恢复后点击重试 | 已缓冲部分可继续播放，耗尽后有缓冲/错误提示；重试重新取流，不无限卡死 |
| ☐ | 网页有地址但媒体加载失败 | 自动尝试备用解析，必要时使用下一档可用画质；保留进度，最多自动恢复两次，不无限循环 |
| ☐ | 切换备用片源期间退出或再切集 | 旧请求不能恢复播放，也不能覆盖新的选择 |

备用解析和多画质项目需要选择能进入相应链路的剧集；网页直链不一定提供多个画质选项。

2026-09-13 接口排查样本：《天神殿》（217 集，系列 ID `7111943588446997534`）。所查网页播放端返回 500/404；备用接口返回 `parse: 0`，但 `url` 等于传入的 Base64 请求，没有实际媒体地址。使用原 Go 工程相同的请求参数和 User-Agent 结果一致。这种响应应显示“片源暂未提供这集的视频地址”，不能冒充播放成功，也不能归为集数超限。

## 调试环境的 MESA 日志

`Failed to find VkFence` 来自图形驱动的 Vulkan 同步路径，不是数据源返回的错误。Android debug 配置已禁用 Impeller，使用 Skia/OpenGL 路径避开模拟器的该兼容问题。需要停止应用后重新执行 `flutter run`，热重载/热重启不能替换原生渲染配置；release 配置不受影响。实际设备上的日志和播放体验仍由人工确认。

## P1 · 剧库、收藏和持久化

- [ ] 首次联网能加载真实剧库；真人剧、漫剧、AI 剧、动漫分类正确。
- [ ] 滑到底部可以继续加载，下拉刷新不重复堆叠同一部短剧。
- [ ] 搜索剧名、题材、标签能匹配已加载内容；无结果时提示清晰，搜索历史可清除。
- [ ] 多个题材、完结/连载状态、60 集内及排序能正确组合；重置筛选有效。
- [ ] 长按封面打开详情，简介和实际分集正确；点击具体集数直接播放该集。
- [ ] 收藏/取消收藏即时反映到封面、播放菜单和“我的”；重启应用后仍一致。
- [ ] 退出播放、切集、切后台后保存准确集数和时间；重启后继续观看位置正确。
- [ ] 关闭“记忆播放进度”后不再写入新记录，下次打开从默认位置播放。
- [ ] “我的”可批量管理收藏/历史；删除记录后不会继续沿用已删除进度。
- [ ] 剧库刷新失败时仍显示旧缓存；失败分类不清空其他分类。
- [ ] 首次无网络时有可理解的空状态和重试入口；恢复网络可正常加载。
- [ ] 清理剧库缓存后收藏、历史、设置保留；重新刷新可恢复剧库内容。

## P1 · 外观与设备体验

- [ ] 桌面图标、启动页和应用内标识正确使用提供的金色 logo。
- [ ] 浅色、深色、跟随系统三种外观生效，并在重启后保留。
- [ ] 默认倍速、优先画质、自动下一集、控制栏位置、手势灵敏度与触感设置持久化。
- [ ] 低/中/高手势灵敏度能体现触发距离差异，低灵敏度更不易误触。
- [ ] 小屏、大字模式下标题、设置行、选集网格、弹出菜单无溢出，所有按钮可点到。
- [ ] 刘海/挖孔屏、手势导航与三键导航下，内容和控制按钮不被系统区域挡住。
- [ ] 搜索键盘弹出、返回关闭弹窗、切换底部标签的行为符合预期。
- [ ] 连续观看、切集和多次进出播放器后，无明显崩溃、声音叠加、持续卡顿或异常内存增长。

本版不包含离线下载、多端同步或 Windows 客户端，不作为本次验收项。
