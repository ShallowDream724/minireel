# Windows 首版验收

在 Windows 10/11 x64 上使用 Release 目录运行。系统快捷键和原生窗口需要在实际桌面验收；测试用例中的播放器使用可控引擎检查状态逻辑。

- [ ] 左侧仅图标的「短剧库」「我的」「设置」可切换，悬停名称和键盘焦点清晰。
- [ ] 宽窗口海报列数随宽度调整；搜索、筛选、收藏、历史和设置可用。
- [ ] 最小化、最大化、关闭、拖动标题栏正常；重启恢复可见的窗口位置和尺寸。
- [ ] 实际视频画面与声音正常，包括直链和备用解析；两端的同一剧目、集数对应相同内容。
- [ ] 空格只切换一次播放状态，长按空格不反复暂停/播放；文字输入时保留空格和方向键。
- [ ] 左右方向键每次 5 秒，Shift 加方向键每次 15 秒；上下方向键只改变应用音量，每次 5%。
- [ ] M 静音后再次按 M 恢复原音量；音量重启后保留。
- [ ] F、Enter 和双击切换全屏，期间画面保持比例、播放进度连续。
- [ ] E 和右键可打开选集/菜单；Esc 先关闭面板，再退出全屏或小窗，最后退出播放。
- [ ] PageUp/PageDown 和选集按钮切集正确；快速切集只播放最后选择的集，首尾边界正确。
- [ ] 控制栏闲置后与光标一起隐藏，鼠标移动后出现；操作进度条、面板或键盘焦点时保持可操作。
- [ ] 缩到窄窗口或打开大字模式，标题、进度、播放和窗口按钮无遮挡或溢出。
- [ ] 适应视频窗口和迷你置顶可进入、恢复；置顶只影响当前 MiniReel 窗口。
- [ ] Alt+Tab 到其他应用继续播放；最小化暂停可在设置中开关。
- [ ] 手动暂停后最小化/还原不会自动播放；锁屏/休眠恢复也不覆盖手动暂停状态。
- [ ] 播放中直接关闭窗口，重开后保留当前集数和进度，退出无残留声音。
- [ ] 整个 Release 目录复制到其他目录后仍能启动；发布包包含数据文件和所需 DLL。
